# AI use disclosure

AI assistance was used to inspect the Stability provider adapter, DSP processing, API/UI integration, tests, and documentation. One real Stability generation was made only after explicit user approval; the saved output and its measured validation results are recorded in [REPORT.md](./REPORT.md). This does not establish repeatability, musical quality, or licensing clearance.

When the operator sets `STABILITY_API_KEY` in the backend environment, the backend sends the user's music prompt and supported settings to Stability AI's Stable Audio 3.0 API. The credential is never sent to the browser or included in application logs. Prompts and generation requests are processed by the provider under its current [Terms of Service](https://stability.ai/terms-of-service) and [Privacy Policy](https://stability.ai/privacypolicy); do not send sensitive material unless authorized.

The request asks the model for instrumental music, but the API has no strict instrumental-only flag and this app does not independently detect vocals. The backend retains provider source audio separately, then processes the actual returned audio to the requested duration at exactly 48,000 Hz, applies loudness normalization and look-ahead peak limiting, and re-measures the encoded output. The response/UI and manifest compare requested and measured duration, sample rate, LUFS, and true peak, marking each passed, failed, or not measured. This DSP work is not a claim of artistic mastering. MP3 conversion depends on an externally installed FFmpeg build with `libmp3lame`; the backend reports a clear error if unavailable; validate its license and availability.

Users may upload WAV or MP3 narration to the application backend for processing with an existing successfully generated track. The upload is size-limited and decoded locally; 10 ms RMS blocks at or above -45 dBFS trigger a smoothed 12 dB music-attenuation target (50 ms attack, 250 ms release), then the mixed output is normalized, measured, stored, and exposed for playback/download. This is signal-level ducking, not speech recognition or voice activity detection. Uploaded narration is not sent to Stability AI. MP3 narration decoding also requires FFmpeg. The UI reports a saved mix only after the backend has persisted and validated its output.

Optional loop processing applies a 250 ms reverse-head/tail edge crossfade to the processed audio and measures the saved file's endpoint discontinuity. The check only measures sample-amplitude continuity and does not prove musical or rhythmic seamlessness. Section times and tempo/key are prompt metadata; estimated bars assume 4/4 and are not detected from the generated recording.

An opt-in SAM-Audio target/residual processing path is implemented, but no SAM weights or inference dependencies are installed and no real SAM outputs have been generated in this workspace. The checkpoint is gated; the account holder must request/accept access to the exact pinned checkpoint and authenticate locally. Model and processor loading use `local_files_only=True`, so the application does not download weights automatically. The SAM license does not expressly establish commercial use; independent legal review is required. The local code prompts for percussion, bass, and other instruments, plus a remaining residual, and displays measured reconstruction error without treating it as proof of source purity. It never substitutes frequency bands or duplicated mix files for model output. No commercially permitted route has been confirmed: AudioShake's output-use terms/API contract are unverified, Demucs/Spleeter pretrained-weight rights were not established, and Open-Unmix umxl weights are CC BY-NC-SA 4.0.

Automated tests use mocked provider HTTP interactions and explicitly identified synthetic test-tone fixtures. They do not call a paid generation API. One optional Stability AI integration test is guarded by `RUN_STABILITY_INTEGRATION_TEST=1` and produces a real request when explicitly enabled with a configured key. Separately, one 5-second live WAV generation was completed after explicit user approval and validated; see [REPORT.md](./REPORT.md). Further paid requests require approval.

Stability AI's current pricing lists eight credits per successful Stable Audio 3.0 generation, with one credit listed as $0.01. This may change; the app does not purchase credits. Provider terms assign output rights to the user to the extent permitted by law and subject to the terms, but the app cannot guarantee uniqueness, copyrightability, or absence of infringement. The user is responsible for prompts and reviewing outputs and applicable terms.
